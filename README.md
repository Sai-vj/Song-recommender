## 🧠 Overview

The **Mood-Based Song Recommender** is a Flask-powered web application that suggests Spotify playlists based on the user’s mood.  
Users log in with their Spotify account, enter how they feel (e.g., *happy*, *sad*, *romantic*, *chill*), and receive curated playlist suggestions instantly.  
All searches are saved in a **history tracker** for easy revisits!

---

## ✨ Features

- 🎧 **Spotify OAuth Login** – Secure login using Spotify authentication  
- 🎯 **Mood-Based Playlist Search** – Finds music based on the user’s mood  
- 🧵 **Clean Flask Architecture** – Modular & well-structured backend  
- 🗂️ **History Tracking with SQLite** – Saves every mood search + playlist suggested  
- ⚡ **Fallback Search Mode** – Works even without login using public Spotify access  
- 📱 **User-Friendly UI** – Simple, minimal music-focused design
