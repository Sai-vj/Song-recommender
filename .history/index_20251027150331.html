HireHive — Full Stack Web App

A full-stack AI-powered Applicant Tracking System (ATS) built with Django, DRF, MySQL, Celery, and Redis. The platform supports secure authentication (JWT) for candidates and recruiters, resume parsing & job matching, and automated tracking of applications (Pending → Shortlisted → Interview → Hired). Recruiters can post jobs, schedule interviews, and send invites directly. Integrated AI-based question & quiz generation using OpenAI API to enhance candidate preparation. The project simplifies hiring workflows and improves recruiter productivity.

Smart Bus Ticketing — Desktop Application

An interactive desktop ticketing application built with Python Tkinter and MySQL. It automates bus fare calculation with a 20% peak-hour adjustment feature and supports QR code payment for quick transactions. Users can instantly generate and save PDF tickets for offline use. The system also integrates voice recognition for effortless input, making the booking process faster and more user-friendly. Designed to improve efficiency and give a modern experience to traditional bus ticket booking.

Song recommender — Backend project

This project is built using Flask and integrates Spotify OAuth authentication to allow users to securely log in with their Spotify accounts. It provides mood-based music recommendations, where users can enter a mood such as “Happy” or “Sad,” and the system fetches curated playlists through the Spotify Web API before redirecting them to Spotify for playback. A database-driven history module was implemented to store user mood searches and playlist selections, enabling personalized suggestions and enhancing the overall user experience.
